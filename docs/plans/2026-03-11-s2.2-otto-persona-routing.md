# S2.2 — Otto Persona Routing: Frontend Wiring

**Date:** 2026-03-11
**Sprint:** 2 (Readiness Audit)

## Problem

Backend persona routing is fully implemented (voice baseline, 17 profile traits, model tier routing, warm-start). But the frontend never sends `persona_mode` in Otto chat requests, and there's no UI to display or select the active persona.

## Current State

**Backend (complete):**

- `agent.py`: Voice baseline, PERSONA_VOICE_TRAITS for 17 profiles, resolve_model_for_persona()
- `enrichment.py`: enrich_persona() fetches from Otto State Service
- `deps.py`: PersonaContext + UserAgentContext dataclasses
- `routes.py`: ChatRequest accepts persona_mode, routes to model tier
- `bridge.py`: Broadcasts persona_mode via WebSocket

**Frontend (gaps):**

- `otto.store.ts`: sendMessage() does NOT send persona_mode
- `mock-messenger.ts`: Conversation.personaMode field exists but never populated
- `ChatView.tsx`: Shows personaMode in header if present (display-only)
- No persona selector UI anywhere

## Plan

### Task 1: Wire persona_mode in otto.store.ts

**File:** `apps/web/src/stores/otto.store.ts` (modify)

- Add `personaMode: string | null` to store state
- Add `setPersonaMode(mode: string | null)` action
- Include `persona_mode` in sendMessage() request body
- Include `persona_mode` in sendMessengerMessage() request body

### Task 2: Wire persona_mode in messenger store

**File:** `apps/web/src/stores/messenger.store.ts` (modify)

- When sending messages via Otto conversations, include conversation's personaMode
- When creating Otto conversations, allow setting initial personaMode

### Task 3: Create PersonaSelector molecule

**File:** `apps/web/src/components/molecules/PersonaSelector.tsx`

- Dropdown/pill selector showing available persona modes
- Modes: default, analyst, executor, guardian, strategist, connector, architect
- Small, inline UI — fits in chat composer area or conversation header
- Calls onSelect callback with selected mode

### Task 4: Add PersonaSelector to OttoChat

**File:** `apps/web/src/components/organisms/OttoChat.tsx` (modify)

- Add PersonaSelector in the chat header area
- Wire selection to otto.store.setPersonaMode()
- Show current persona mode indicator

### Task 5: Add PersonaSelector to messenger Otto conversations

**File:** `apps/web/src/components/organisms/ChatView.tsx` (modify)

- When conversation.type === "otto", show PersonaSelector in header
- Wire to messenger store persona handling
