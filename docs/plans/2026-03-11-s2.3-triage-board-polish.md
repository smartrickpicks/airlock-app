# S2.3 — Triage Board Polish: Kanban + Table + Agenda Views

**Date:** 2026-03-11
**Sprint:** 2 (Readiness Audit)

## Problem

The `/contracts/triage` page currently shows a grid of vault cards + VaultGantt timeline. The Triage module spec requires 3 switchable views: Kanban board, sortable table, and agenda — matching the Tasks module's existing patterns.

## Current State

- `/contracts/triage/page.tsx` — Grid cards + VaultGantt, filter by discover chamber
- TasksKanban, TasksTable, AgendaList components exist for Tasks module
- `tasks.store.ts` — 24 mock tasks with module/severity/status fields
- No triage-specific store or view switcher on /contracts/triage

## Plan

**File:** `apps/web/src/components/organisms/TriageKanban.tsx`

- Adapt TasksKanban pattern for triage context
- 4 columns based on triage task status: Open → In Progress → In Review → Resolved
- Filter to contracts-module tasks only
- Drag-drop reordering (reuse @hello-pangea/dnd pattern from TasksKanban)
- Each card: task title, vault name, severity badge, assignee, SLA timer

### Task 2: Create TriageTable organism

**File:** `apps/web/src/components/organisms/TriageTable.tsx`

**File:** `apps/web/src/components/organisms/TriageAgenda.tsx`

**File:** `apps/web/src/app/(shell)/(modules)/contracts/triage/page.tsx` (rewrite)
