# S3.3 — Admin Members: Invite Management UI

**Date:** 2026-03-11
**Sprint:** 3

## Problem

Admin members page exists with MembersTable and role management. S1.4 built the invite API (POST create, GET validate, POST accept). But there's no UI to create invites or see pending invites.

## Plan

### Task 1: Create InviteModal molecule

**File:** `apps/web/src/components/molecules/InviteModal.tsx`

- Modal form: email input, role selector (builder/gatekeeper/owner/viewer), optional message
- "Send Invite" button calls POST /api/v1/invites
- Shows success/error state
- Mock fallback creates local invite

### Task 2: Create PendingInvitesList molecule

**File:** `apps/web/src/components/molecules/PendingInvitesList.tsx`

- Lists pending invites with: email, role, invited by, expires, status
- Action: resend, revoke
- Fetches from invite service list endpoint

### Task 3: Add invite UI to admin members page

**File:** `apps/web/src/app/(shell)/admin/members/page.tsx` (modify)

- Add "Invite Member" button in header that opens InviteModal
- Add PendingInvitesList section below MembersTable
- Wire to admin store or create invite-specific state

### Task 4: Add invite list endpoint to API

**File:** `apps/api/src/routes/invites.py` (modify)

- `GET /api/v1/invites` — list pending invites for workspace (admin only)
- Returns: email, role, status, created_at, expires_at, invited_by
