# S3.4 — Workspace Branding: Logo + Accent Color

**Date:** 2026-03-11
**Sprint:** 3

## Problem

WorkspaceConfig model has `logo_url` and `accent_color` fields. Admin workspace page exists but uses mock data. No API endpoint to update branding. No logo upload UI.

## Plan

### Task 1: Add workspace config update endpoint

**File:** `apps/api/src/routes/workspaces.py` (modify)

- `PATCH /api/v1/workspaces/me/config` — update workspace config fields
- Accepts: name, industry, logo_url, accent_color
- Only workspace admins can update
- Pydantic model: WorkspaceConfigUpdate

### Task 2: Add workspace config fetch to GET /me

**File:** `apps/api/src/routes/workspaces.py` (modify)

- Enrich GET `/api/v1/workspaces/me` response with branding fields from workspace_config
- Return: name, slug, industry, plan, logo_url, accent_color, member_count

### Task 3: Wire admin workspace page to API

**File:** `apps/web/src/app/(shell)/admin/workspace/page.tsx` (modify)

- Fetch workspace data from `/api/v1/workspaces/me` on mount (mock fallback)
- Save changes via PATCH `/api/v1/workspaces/me/config`
- Add logo upload section: file input + preview
- Add accent color picker: preset swatches + custom hex input
- Show save confirmation
