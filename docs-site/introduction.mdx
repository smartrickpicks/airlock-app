## What is Airlock?

Airlock is a Discord-style interface for contract lifecycle management. It organizes every deal, relationship, and piece of data your team works with into a clean, structured hierarchy — and puts AI at the center of the workflow.

## Key Concepts

Airlock has its own vocabulary. Learn these terms before diving in.

| Airlock Term | What it means |
|---|---|
| **Vault** | A workflow instance — one contract, one deal, one entity |
| **Module** | A top-level domain: Contracts, CRM, Tasks, Calendar, Documents |
| **Chamber** | A lifecycle stage within a module (Discover → Build → Review → Ship) |
| **Gate** | A checkpoint between chambers |
| **Triptych** | The three-panel layout: Signal \| Orchestrate \| Control |
| **Otto** | The AI agent embedded in every vault |
