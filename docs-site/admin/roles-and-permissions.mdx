## Overview

Admins manage the three-layer role system from this section. See [Core Concepts: Roles](/concepts/roles) for the full explanation of how layers interact.

## Assigning Org Roles

Org roles are set per user across the workspace. Navigate to **Admin → Members** to assign or change a user's org role.

## Configuring Module Roles

Module roles are set per user per module. A user can be a `builder` in Contracts and a `viewer` in CRM simultaneously.

## Custom Roles (Post-MVP)

<Note>
  Custom roles are post-MVP.
</Note>

Custom roles will allow admins to:
- Create unlimited named roles
- Assign granular permission checkboxes from the full permission catalog
- Drag-to-reorder role hierarchy
- Assign multiple roles per user (additive permissions)
- System base roles (Builder / Gatekeeper / Owner / Designer / Viewer) remain as non-deletable defaults
