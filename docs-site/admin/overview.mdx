## Overview

Admin is the **Overlay** — a system-level settings surface that sits above modules. It is not a module itself. Access is restricted to Director and Executive org roles.

## Workspace Admin (9 sections)

1. General — workspace name, logo, timezone
2. Members — invite, remove, org role assignment
3. Roles & Permissions — module role configuration
4. Modules — enable/disable modules per workspace
5. Feature Control Plane — toggle and calibrate AI engines
6. Contract Templates — manage the clause library and templates
7. Playbooks — configure chamber flows and gate rules
8. Integrations — connect external tools
9. Billing — subscription and usage

## Personal Settings (5 sections)

1. Profile — name, avatar, timezone
2. Notifications — per-module notification preferences
3. Appearance — (locked to OLED dark for now)
4. Connected Accounts — OAuth connections
5. API Keys — personal API token management
