## Endpoint

```
GET /v1/vaults
```

## Query Parameters

| Parameter | Type | Description |
|---|---|---|
| `module` | string | Filter by module (`contracts`, `crm`, `tasks`) |
| `chamber` | string | Filter by chamber (`discover`, `build`, `review`, `ship`) |
| `assignee_id` | string | Filter by assigned user ULID |
| `limit` | integer | Max results (default: 50, max: 200) |
| `cursor` | string | Pagination cursor from previous response |
