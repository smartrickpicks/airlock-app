---
title: Create Event
description: POST /vaults/:id/events — append a custom event to a vault's log.
---

<Note>
  **Build status:** Not yet built.
</Note>

## Endpoint

```
POST /v1/vaults/:id/events
```

## Request Body

```json
{
  "event_type": "custom.note",
  "payload": {
    "message": "Client confirmed new territory scope via email."
  }
}
```

## Response

```json
{
  "data": {
    "id": "01HEVT...",
    "vault_id": "01HXYZ...",
    "event_type": "custom.note",
    "actor_id": "01HUSR...",
    "payload": {
      "message": "Client confirmed new territory scope via email."
    },
    "created_at": "2026-03-08T14:00:00Z"
  }
}
```

Custom events appear in the vault's Signal panel activity feed.
