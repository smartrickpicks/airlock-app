## How contracts move through chambers

```
DISCOVER → BUILD → REVIEW → SHIP
```

1. **Discover** — Document uploaded, Otto extracts all fields
2. **Build** — Team reviews extraction, proposes patches, resolves conflicts
3. **Review** — Gatekeeper approves the vault
4. **Ship** — Contract is executed and filed
