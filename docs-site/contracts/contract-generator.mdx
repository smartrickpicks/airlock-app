## Overview

The Contract Generator creates new contracts from a library of 24 templates. It uses a two-pane interface: the builder form on the left, live preview on the right.

## Template Library

**5 industry verticals, 24 contract types:**

| Vertical | Templates |
|---|---|
| Music | Recording, Publishing, Distribution, Co-Publishing, Sync License, Management |
| Film | Film Distribution, Director, Talent/Actor, TV Talent, TV Licensing |
| Live & Events | *(coming soon)* |
| Business | NDA, Producer |
| *(more)* | License |

## Clause Library

The v2 clause library contains **188 clauses** across all contract types. Clauses are:

- Versioned — changes are tracked
- Conditional — shown/hidden based on deal type answers
- Configurable — admins can modify clause text in Admin settings

## Two-Pane Builder

**Left pane** — a structured questionnaire. Answers drive which clauses appear and how variables are populated.

**Right pane** — live rendered preview of the contract as you fill in the form.

## Output

Generated contracts are saved as a new vault in the Contracts module, pre-populated with all fields from the generation session. The vault enters at the Build chamber — Discover is skipped since the document was generated (not uploaded).

<Tip>
  The Admin panel includes a **Template Compiler** that lets you build new templates from a corpus of existing documents using Otto.
</Tip>
