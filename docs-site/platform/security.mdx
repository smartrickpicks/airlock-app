## Architecture

Airlock is designed cipher-first:

- **Row-Level Security (RLS)** — PostgreSQL RLS enforced via `workspace_id` on every table. Cross-tenant data leakage is impossible at the database level.
- **Soft deletes** — No data is hard-deleted. All records have `deleted_at` timestamps.
- **Audit log** — Every mutation is recorded in the events table (append-only).
- **ULID primary keys** — No sequential IDs that expose record counts.

## Authentication

- JWT-based auth with short-lived access tokens
- Refresh token rotation
- OAuth 2.0 support for SSO (post-MVP)

## API Security

- All API routes require authentication
- Role checks enforced at the service layer (not route handlers)
- Rate limiting via Redis
