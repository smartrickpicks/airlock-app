## How to read this

| Column | Meaning |
|---|---|
| **Spec** | Design specification written and decisions locked |
| **Built** | Code shipped — backend + frontend complete |
| **Docs** | Mintlify page written (not a stub) |
| **MVP** | Required for MVP launch |

### Status icons
- ✅ Done
- 🔨 In progress
- ⬜ Not started
- 🚫 Post-MVP (out of scope for v1)
